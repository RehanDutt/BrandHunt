# BrandHunt: Sponsorship Intelligence Engine

**BrandHunt** is a high-performance lead acquisition suite designed to automate the discovery and verification of brand sponsors for large-scale events. Built for speed and precision, it transforms hours of manual research into a 60-second intelligence sweep.

### Key Features
**Live Brand Discovery**: Scrapes real-time market data to identify high-affinity brand partners.
**Lead Verification**: Integrated with Hunter.io to find and verify corporate marketing leadership contacts.
**Minimalist UI**: An Apple-inspired, professional interface designed for stakeholder presentations.
**Secure Architecture**: Implements environment-based credential management for enterprise safety.

### Tech Stack
*Language**: Python
**Frontend**: Streamlit (Custom CSS)
**APIs**: Serper.dev (Google Intelligence), Hunter.io (Email Verification)
**Data**: Pandas, XlsxWriter
